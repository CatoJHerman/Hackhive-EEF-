AUDIO
264 rows, 264 unique recording IDs, 8 expected columns, no missing or non-finite
values, no duplicate rows or feature rows. All windows run from 0 to 1 second
at 44100 Hz. RMS/peak/crest consistency and frequency bounds pass.
The CSV cannot establish raw recording quality, clipping rate, source authenticity,
independence, or how much source audio was skipped. Those require original WAVs.
Dominant frequencies range from 6 to 1811 Hz; these were retained, not treated as
faults or automatically removed as outliers.

OBD
118477 rows, 26 columns, no missing cells. 90657 exact duplicates; 27820 unique rows.
4391 raw rows (1338 unique) have all 14 code flags zero, including P0000.
They are ambiguous and have a blank target, not an invented healthy label.
The remaining 26482 unique rows have explicit label patterns:
  6732: P0000=1, every other provided code=0.
  19750: P0000=0 and at least one other provided code=1.
These labels describe code status, not guaranteed physical health or future wear.
Several code columns are identical, and there are only seven distinct code-label
patterns including the ambiguous pattern. Individual fault claims are limited.
No identical sensor-vector groups with conflicting code labels were found.

Use obd_explicit_labels.csv for initial exploratory code-status modelling.
Use only these inputs:
LOAD_PCT, ECT, MAP, RPM, VSS, IAT, MAF, FRP, BARO, VPWR, AAT
Target: recorded_fault_code_present.
Exclude all P-code columns, Mode, source_excel_row and label_status from inputs.
Mode semantics are unverified. Retain its values only as metadata for now.
All original units were preserved. Temperature and pressure ranges conflict with
the repository's stated metric units; verify before physical interpretation or
converting. Do not treat raw spreadsheet row order as a measured time axis.

No vehicle/session IDs or timestamps exist in this supplied workbook. Deduplication
does not make samples independent. Recover grouping information and obtain the
independent test workbook before making generalisation claims. Check train/test
overlap, and keep vehicles/sessions together. Do not derive groups from target codes.

OBD source: https://github.com/AbouAbdallah-Lounis/OBD-Dataset
Source model code confirms that P-code columns are targets:
https://github.com/AbouAbdallah-Lounis/OBD-Dataset/blob/main/MODEL.py
Repository lists CC BY 4.0. Attribute Karim Lounis, Hadjer Mekki and Wissam Hadjab,
DieselOBD (2025). Derived copies remove exact duplicates and quarantine ambiguous
labels; the original workbook is unchanged.
